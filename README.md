### 🚀 About the Project  
Flat Finder is a mobile application designed to simplify the search for **flats, PG accommodations, and roommates**. Whether you're looking for a shared living space or a private rental, this app helps you find the best options with ease.  

---

### ✨ Features  
✔ **Search for Flats & PGs** – Browse through a list of available rentals 📍  
✔ **Find Roommates** – Connect with people looking for shared accommodation 🤝  
✔ **Advanced Filters** – Sort listings by budget, location, and preferences 🔍  
✔ **Contact Owners** – Directly get in touch with property owners and roommates 📩  
✔ **Smooth UI/UX** – Simple, fast, and user-friendly experience 🎨

### 🏗 Installation & Setup  
1️⃣ **Clone the Repository**  
```bash
git clone https://github.com/abhi96088/Flat-Finder.git
cd Flat-Finder
```
2️⃣ **Install Dependencies**  
```bash
flutter pub get
```
3️⃣ **Run the App**  
```bash
flutter run
```
(*Make sure you have Flutter SDK installed and connected to an emulator or device.*)
